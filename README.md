# LjubljanaHNAWorkshop
Materials for workshop on Historical Network Analysis in Ljubljana (October 2026)

## Contents

### Historical network analysis: theory, concepts, applications
* What is historical network analysis? Current and past projects working with HNA.
* Graph theory: sets, vertices, edges, graphs, subgraphs. Exercise: create a CSV of edges and visualize it on Network Navigator
* Historical network analysis (HNA): principles, concepts, workflows.

### Introduction to Gephi
* Understanding the interface.
* Import files and previsualization.
* Parameters: sizes, labels, colors.
* Layout algorithms.
* Filters and statistics.
